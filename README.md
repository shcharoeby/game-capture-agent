# OldenLeague Game Capture

Приложение для автоматического захвата и трансляции игровых сессий Heroes of Might and Magic: Olden Era на турнире [OldenLeague](https://oldenleague.ru).

## Возможности

- **Авто-детект игры** — запускается автоматически когда обнаруживает процесс игры
- **Захват окна по PID** — не зависит от z-order, работает при Alt+Tab (PrintWindow API, как OBS BitBlt)
- **Захват звука только из игры** — WASAPI Process Loopback, без Стерео микшера (Windows 10 2004+)
- **Адаптивный битрейт** — снижает качество при росте буфера, восстанавливает когда сеть стабилизируется
- **RTMP и SRT** — поддержка обоих протоколов
- **Авто-обновление** — при запуске проверяет новые версии, скачивает только изменившиеся файлы

## Установка

Скачайте `GameCapture-Setup-x.x.x.exe` со [страницы релизов](https://github.com/shcharoeby/game-capture-agent/releases/latest) и запустите.

- Устанавливается в `%LOCALAPPDATA%\Programs\GameCapture\` — **права администратора не нужны**
- Настройки и логи хранятся в `%APPDATA%\GameCapture\` и не перезаписываются при обновлениях

## Системные требования

- Windows 10 версии 2004 (сборка 19041) или новее
- Для захвата звука из игры: Windows 10 2004+ (WASAPI Process Loopback)

## Использование

1. Запустите `game-capture.exe` (или через ярлык в Пуске)
2. Укажите адрес сервера и ключ трансляции в главном окне
3. Запустите игру — трансляция начнётся автоматически через 5 секунд
4. Значок в трее показывает текущий статус

## Для разработчиков

### Требования
- Python 3.11+
- `pip install -r requirements.txt`
- `vendor/ffmpeg.exe` — см. `vendor/README.md`
- Inno Setup 6 (для сборки установщика)

### Сборка
```bash
./build.sh
```

### Релиз
```bash
./release.sh 1.2.3 "Описание изменений"
```

Скрипт собирает exe, генерирует `version.json` с sha256-суммами, собирает установщик Inno Setup и публикует релиз на GitHub.
